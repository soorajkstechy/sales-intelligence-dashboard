# Sales Intelligence Dashboard

A full-stack sales analytics dashboard with React frontend, Node.js API, and SQL backend.

## Tech Stack
React · Node.js · Express.js · SQL · Power BI · DAX · Material UI · Bootstrap

## Features
- Interactive drill-through filters and KPI cards
- Customer segmentation and regional revenue tracking
- Identified 3 underperforming regions — adopted as team-wide reporting standard
- DAX measures for real-time data calculation

## Architecture
React Frontend → Node.js/Express API → SQL Database → Power BI Reporting Layer

## Results
| Metric | Result |
|--------|--------|
| Regions Identified | 3 underperforming regions flagged |
| Stakeholders | Non-technical team adopted as standard |
| Filters | Drill-through + KPI cards + DAX measures |

## Setup
```bash
# Backend
cd server && npm install && node index.js

# Frontend
cd client && npm install && npm start
```
